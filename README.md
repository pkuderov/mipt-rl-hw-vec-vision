## Задание №1. RL for POMDP GridWorld

В данном задании предлагается пройти следующий путь: а) создать векторизованную клеточную среду GridWorld для задачи поиска и навигации с неоднозначными наблюдениями, б) решить ее любым RL алгоритмом, используя полученные в семестре знания. _Далее идет подробное описание среды, а в конце --- список общих рекомендаций по выполнению задания_.

### Клеточная среда

Реализуйте виртуальную клеточную среду-лабиринт, аналогичную классическому GridWorld.

Среда представляет собой прямоугольную область размера $(h, w)$ (гиперпараметры инициализации), окруженной стеной. Внутри области могут быть расположены препятствия (задается бинарной 2д маской `obstacle_mask`, параметр инициализации). Агент может перемещаться по среде с помощью четырех действий-направлений (пронумеруйте по часовой, начиная с "вверх").

Цель агента --- добраться до целевой позиции `pos_goal`, которая задается случайно в начале каждого эпизода. Стартовая позиция агента `pos_agent` тоже случайно сэмплируется в начале эпизода.

У каждой клетки среды есть свой тип: пол (пустая клетка), стена (=обрамляющая граница области), препятствие (недоступная для перехода клетка внутри области). Каждый тип имеет свой набор цветов покраски. Всего `n_colors` цветов, из которых стены и препятствия имеют по одному отдельному цвету, и пол может иметь один из остальных `n_colors - 2` цветов. В задании `n_colors` $\le 10$. Среда принимает в кач-ве параметра инициализации 2д массив размера $(h, w)$ с покраской внутренней области лабиринта. Карта с покраской фиксированы и одинаковые на протяжении всего обучения. Для удобства реализуйте следующие функции-хелперы: а) случайное расставление препятствий на карте, б) случайная покраска пола в нужное число цветов. Не забудьте использовать контроллируемый генератор случайных чисел в качестве параметра этих функций для удобства воспроизводимости.

На каждом шаге агент получает от среды цель `goal` и наблюдение `obs`. Наблюдение агента содержит представление одной клетки. Еcли на прошлом шаге он попытался пойти в клетку со стеной/препятствием, то по механике среды он остается на месте, но "видит" клетку стены/препятствия. Иначе он наблюдает текущую клетку под ногами. Представление клетки в наблюдении формируется следующим образом: на основе индекса цвета клетки случайно выбирается изображение (=рукописное представление цифры) из соответствующего класса датасета MNIST. В качестве представления цели в наблюдении агента можно рассмотреть варианты на основе абсолютных координат (обычное two-hot кодирование) или на основе некоторого небольшого окна наблюдения (напр, 3x3, 5x5) с центром в цели. В последнем варианте берется выбранная область карты, далее цвета выбранных клеток переводятся аналогично наблюдению в изображения из MNIST и затем конкатенируются.

Функция вознаграждения разреженная: 1 за достижение цели, 0 в остальных случаях.

Необходимо, чтобы среды была векторизованной и реализовывала стандартный интерфейс `gymnasium.VecEnv` (см. [документацию gymnasium](https://gymnasium.farama.org/api/vector/#)). Можно не досконально (например, работу с рнг можно сделать по-своему). Важно, чтобы ограничение на длину эпизода задавалось так же, в среде корректно задавались `observation_space` и `action_space`, а также интерфейс `reset()` и `step()` соответствовали интерфейсу. При реализации векторизации рекомендуется обратить внимание на [эту статью](https://farama.org/Vector-Autoreset-Mode).

В качестве тестирования предлагается следующий набор размеров среды: 10x10, 20x20, 30x30. Во всех случаях используйте 10-15% препятствий, `n_colors=10`.

## Задание №2. RL for Active Vision

В данном задании предлагается решить задачу классификации изображений как POMDP RL задачу, где агент перемещается по изображению как в клеточном мире с целью его распознать. Агент стартует из случайной точки на изображении и на каждом шаге видит лишь ограниченное окно пикселей вокруг себя, решая либо куда переместиться дальше, либо предсказывая класс изображения.

Требуется реализовать векторизованную клеточную среду для датасета CIFAR-10 (рекомендации те же, что и для Задания №1). Пространство действий агента имеет несколько компонент:

- тип действия: перемещение или предсказание класса
- предсказание класса: категориальное распределение
- перемещение: можно сделать непрерывное из двух частей (угол и дальность прыжка) или дискретное (одно из 4х направлений и дальность прыжка). Стоит ограничить длину прыжка 8 пикселями.

Наблюдение агента: небольшое окно WxH (не больше 7x7) пикселей вокруг агента. Желательно работать с цветными (не grayscale) изображениями. Возможно стоит добавить нормализацию наблюдений агента.

Функция вознаграждения разреженная: 1 за достижение цели, 0 в остальных случаях. Эпизод заканчивается по лимиту времени. Что делать при даче неправильного ответа --- завершать эпизод или продолжать его со штрафом --- выберите сами.

### Рекомендации

- Для дебага имеет смысл начать с более простых сетапов и так же позапускать на прямоугольных размерах для проверки, что оси нигде не перепутаны.
